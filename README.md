# 待办岛 GitHub 版

待办岛是一款安卓本地待办工具，支持日待办、周待办、桌面小组件和可选的手机日历同步。最低支持 Android 8.0。

## 下载与安装

从 [Releases](https://github.com/D0ngfore/Todo-Island/releases/latest) 下载 APK。可用 [SHA256SUMS.txt](SHA256SUMS.txt) 核验下载文件。官方 GitHub 版 APK 的证书主题为 `CN=Zhao`，应用包名为 `com.todoisland.mobile.github`。

GitHub 版可与商店版并装，两者各自保存本机数据。需要迁移待办时，可在原版「设置 → 本地待办备份」导出，再在 GitHub 版导入。导出文件含待办正文，请在自己的设备上处理。
